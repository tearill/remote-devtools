确保手机和电脑在同一 Wi-Fi 网络下，然后在手机 Wi-Fi 设置中配置 HTTP 代理：

-

  2. 滚动到底部，点击 配置代理 → 手动
  3. 填写服务器地址和端口（见上方）
  4. 点击「存储」保存设置
  1. 前往 设置 → WLAN，长按当前连接的 Wi-Fi
  2. 选择 修改网络 → 高级选项
  3. 将代理设置为 手动，填写主机名和端口（见上方）
  4. 保存设置

常见问题
Q：电脑浏览器仍然显示「不安全」警告？
请确认已执行 mkcert -install 将根证书安装到系统信任存储中，然后点击「重新生成」证书并重启服务。
Q：手机无法访问 HTTPS 页面？
请检查：1) 手机和电脑是否在同一网络下；2) rootCA.pem 是否已安装并信任；3) 证书是否覆盖了当前电脑的 IP 地址。
Q：证书过期了怎么办？
mkcert 生成的证书有效期约 2 年，点击「重新生成」即可创建新证书。
Q：可以使用自己的证书吗？
可以，展开上方「手动指定证书（可选）」面板，指定自定义的证书和私钥文件路径即可。
